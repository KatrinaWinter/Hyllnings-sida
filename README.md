<h1> Hyllnings sida </h1>
<p> En Hyllning till Amelia Earheart, ett skolprojekt </p>
<h2> Projektöversikt <h/2>

<p> Detta projekt är en responsiv hyllningssida skapad med HTML och CSS.
Syftet är att presentera Amelia Earhart på ett visuellt och strukturerat sätt, samtidigt som grundläggande tekniker inom modern webbutveckling tillämpas.</p>

<h2>Mål</h2>
<ul>
    <li>Bygga en semantiskt korrekt webbsida </li>
    <li>Skapa en tydlig och tilltalande layout </li>
    <li>Arbeta med responsiv design </li>
    <li>Implementera grundläggande interaktiva effekter </li>
</ul>
<h2>Funktioner</h2>
<ul>
 <li>Responsiv layout med Flexbox och CSS Grid </li>
 <li>Bildgalleri med dynamisk grid-struktur </li>
 <li>Hover-effekter och transitions </li>
 <li>Anpassad typografi med Google Fonts </li>
 <li>Tillgänglighetsanpassningar (alt-texter och skalbara enheter) </li>
</ul>
<h2>Tekniker</h2>
<ul>
 <li>HTML5 – semantisk struktur (header, main, section, footer) </li>
 <li>CSS3 – layout (Flexbox & Grid), styling och effekter </li>
 <li>Google Fonts – typografi </li>
</ul>
<h2>Designprinciper</h2>

<p>Projektet är inspirerat av en klassisk och lätt “vintage” estetik för att spegla Amelia Earharts era.</p>
<h3>Fokus ligger på:</h3>
<ul>
 <li>tydlig hierarki </li>
 <li>läsbarhet </li>
 <li>balans mellan text och bild </li>
</ul>
<h2> Innehåll</h2>
<ul>
 <li>Biografisk introduktion </li>
 <li>Reflektion kring inspiration och påverkan </li>
 <li>Lista över centrala prestationer </li>
 <li>Bildgalleri </li>
 <li>Källförteckning </li>
</ul>
<h2>Lärdomar</h2>

<p>Genom projektet har jag utvecklat förståelse för:</p>
<ul>
 <li>hur HTML-struktur och CSS samverkar </li>
 <li>hur layoutsystem som Flexbox och Grid används i praktiken </li>
 <li>vikten av responsiv och tillgänglig design </li>
</ul>
